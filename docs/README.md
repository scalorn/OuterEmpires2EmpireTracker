# OE2 Empire Tracker — Help

Welcome to the OE2 Empire Tracker documentation. This application helps you manage your empire in Outer Empires 2 by tracking colonies, blueprints, surveys, delivery routes, and player profiles.

## Topics

- [Getting Started](getting-started.md) — Initial setup, creating a player profile, and general workflow
- [Colonies](colonies.md) — Colony import, structures, commodities, and daily build operations
- [Blueprints](blueprints.md) — Blueprint import, market import, evolution chains, and filters
- [Surveys](surveys.md) — Survey import and resource viewing
- [Delivery Routes](delivery-routes.md) — Route planning, auto-fill, and delivery execution
- [Player Profiles](player-profiles.md) — Skills, ranks, and profile management
- [Background Processing](background-processing.md) — Automatic timer processing and status bar indicators
- [Window State](window-state.md) — Window position persistence and MDI layout options

## About

OE2 Empire Tracker is a personal project built by a long-time developer to scratch a real itch — managing a growing OE2 empire without drowning in spreadsheets. It's function over form (the developer freely admits UI design is not their forte), but it gets the job done. If it helps you too, that's a win.

## Quick Tips

- Use **F1** at any time to open context-sensitive help for the form you are currently viewing.
- Use **Help → Contents** (or **Ctrl+F1**) to open this table of contents.
- Data is saved automatically to JSON files — there is no separate "save" step for most operations.
- The status bar at the bottom of the main window shows the next background processing time and current resource usage.
