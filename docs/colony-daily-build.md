# Colony Daily Build

The Colony Daily Build form streamlines your daily build routine. Select a delivery route and see all colonies on that route with staged structures ready to build, grouped by colony. One click per colony to start all builds.

## Opening the Colony Daily Build Form

Open **Manage → Colony Daily Build** from the menu bar.

## Workflow

1. **Select a route** — Use the route dropdown (with text filter) to pick a delivery route. The form shows all colonies on that route.
2. **Review staged structures** — Each colony section shows a grid of structures that are staged and ready to build. The grid shows the structure name, the item being built, current status, and estimated build time.
3. **Build** — Click **Build All** on a colony to initiate construction on all its staged structures. The structures transition from "Staged" to "Building" with countdown timers.
4. **Move to the next colony** — Repeat for each colony on the route.

## Build Time

Build time is calculated based on the structure's blueprint and the colony owner's Builder skill level. Higher Builder skill reduces construction time.

## What Shows Up

Only colonies with at least one staged structure appear. Colonies with no staged structures are hidden to keep the view clean. Once all structures at a colony are building or built, that colony's section updates accordingly.

## Typical Use

This form is designed for the daily routine of logging in, flying your delivery route, and starting builds at each colony. Instead of opening each colony form individually, you get a single view of everything that needs building across your route.
